# Sales Forecasting Project

## Overview
This project focuses on time-series sales forecasting using historical data from 2020–2022, covering multiple product categories.

## Methodology
- Prophet-based time-series modeling
- Daily and weekly aggregation
- External regressor: COVID-19 policy stringency index
- Evaluation using MAE and MAPE

## Output
- Weekly sales forecasts for a 3-year horizon
- Forecast tables (CSV & Excel)
- Visualization of historical and forecasted trends
